# 2026-06-19 AI 学习 small step

## 今天学到了什么

今天把 Skill 的结构和真实实践连在了一起。之前我只是粗略知道 Skill 有文件结构；这次自己动手做了一个 `github-learning-log`，还同时用到了 Skill Creator 和 Superpowers，才更具体地理解了它为什么能减少和 Codex 协作时的摩擦。

我现在对 Skill 的理解大概是三层：

- metadata：告诉 Agent 这个 Skill 是什么、什么时候应该触发
- instructions：告诉 Agent 在这个任务里应该怎么做、遵守什么规则
- scripts 和 references：把重复动作和参考标准沉淀下来，减少每次都靠 prompt 临时说明

## 今天的小 insight

这次最大的感受是：学习新概念和精准表达是互相强化的。

如果我只说“我想做一个智能体对话”，AI 可能会做出最普通的聊天功能；但如果我能说出 RAG、scripts、references、metadata、workflow 这些更具体的词，它就更容易理解我要的结构。

也就是说，懂得越多，不只是“知道更多知识”，还会直接影响我能不能把需求翻译成 AI 可以执行的形式。

## 一个具体例子

如果我只说“做一个 Chatbot”，结果可能只是一个普通聊天框。

但如果我说“希望它有 RAG 能力，用外部知识库检索来减少幻觉”，那设计方向就会完全不同。它会开始涉及知识库、向量化、语义相似度、检索结果和回答生成之间的关系。

Skill 也是类似的。如果我只说“整理笔记”，那可能只是生成一段总结；但如果我知道可以把规则写进 references，把重复动作放进 scripts，就能把它变成一个可复用的工作流。
