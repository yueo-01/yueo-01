# 2026-06-18 AI 学习 small step

## 今天学到了什么

今天理解了 Codex skill 的基本结构：它不是把所有内容一次性塞给 agent，而是用“渐进式披露”让 agent 在需要的时候再加载对应信息。

我现在理解的三层结构是：

- 元数据层：始终可见，用来判断这个 skill 什么时候应该被触发
- 指令层：触发 skill 后按需加载，告诉 agent 应该怎样做
- 资源层：包括 references 和 scripts，只在需要时读取或执行

我也梳理了一下 skill 和 MCP 的区别：

- MCP 更像是给 agent 提供数据、工具或外部能力
- skill 更像是教 agent 如何处理一类任务和工作流

## 今天的小 insight

一个适合长期使用的 AI 学习流程，应该把“私人思考”和“公开输出”分开。

Obsidian 可以保留原始笔记、语音转文字、还没整理好的想法；GitHub 更适合展示已经筛选过、可以公开的 small steps。这样既能保留真实学习过程，也不会把私人内容误发出去。

所以今天顺手做了一个 `github-learning-log` skill 的第一版规则：

- `publish: github` 才允许整理成公开文字
- `assets: github` 才允许发布图片
- push 到 GitHub 前必须再次确认
