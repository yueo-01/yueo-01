# 2026-06-18 AI Learning Log

## Today I Learned

I learned how Codex skills use progressive disclosure to keep an agent focused without loading every detail into context at once.

The structure has three layers:

- metadata is always visible and decides when the skill should trigger
- instructions are loaded when the skill is used
- resources such as references and scripts are loaded or executed only when needed

I also clarified the difference between skills and MCP:

- MCP gives an agent access to data or tools
- a skill teaches the agent how to handle a task or workflow

## Key Insight

A useful AI workflow should separate private thinking from public output. Obsidian can hold raw notes, voice thoughts, and messy drafts, while GitHub can show the small public steps that are safe and useful to share.

This led me to build a first version of a `github-learning-log` skill with explicit publishing hooks:

- `publish: github` for public text
- `assets: github` for approved images
- confirmation before pushing to GitHub
